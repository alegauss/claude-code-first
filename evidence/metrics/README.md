# Corpus metrics

`metrics.json` and `metrics.csv` hold the same figures for all five projects, each counted
from git at the project's pin in [../corpus.md](../corpus.md). They are generated by
`python scripts/corpus_metrics.py`, whose docstring states how every field is counted,
and they are never edited by hand. A figure the specification quotes about the corpus is
taken from here, so a rerun at the same pins reproduces it and a re-pin updates it.

Two fields are estimates and say so: `every_turn_tokens` divides bytes by four, and
`test_declarations` counts declared tests, not the cases a runner collects. MCP tool
schemas are not in any tree and are not counted in `every_turn_bytes`.
