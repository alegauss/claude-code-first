# Findings register

A finding is one claim about Claude Code first practice, synthesised across the case
studies and graded on the scale in [../grading.md](../grading.md). Rules in the
specification cite findings, never case studies or field notes directly. Where five
observations in five ledgers say the same thing, the register holds one finding with
five observations. Where two projects contradict each other, the finding records both.

The list of findings, by topic and grade, is [index.md](index.md). It is generated by
`python scripts/index_findings.py`, and CI fails when it is out of date.

## Identifiers

A finding is named `F<n>`, a namespace separate from the backlog's `CCF` ids. Numbers
are never reused. Each topic owns a block of numbers so that findings written in parallel
cannot collide:

| Topic | Block |
|---|---|
| Context economy and agent prose | F1-F99 |
| Planning, recording, and what the person decides | F100-F199 |
| Commits and concurrent sessions | F200-F299 |
| Gates, verification, and hooks against instructions | F300-F399 |
| Environment, permissions, and agent-facing products | F400-F499 |

## The form of a finding

Each finding is one file, `F<n>.md`, in this shape:

```markdown
# F<n> <the claim, as a title>

| Field | Value |
|---|---|
| Status | active |
| Topic | <one topic from the table above> |
| Grade | R<1-4>/S<1-4> |
| Cases | <the projects where it holds> |
| Contrary | <the projects where it does not, or none> |
| Harness facts | <H ids from harness.md, or none> |

## Claim

One sentence.

## Mechanism

What produces the effect, in a few sentences.

## Observations

One bullet per project, each with pointers in the grammar of ../method.md.

## Independence

Which observations are independent origins and which are copies, per the rules in
../grading.md.

## Counter-evidence

What speaks against the claim, or "None found at the pins."

## Grade

Why the recurrence and strength grades are what they are.
```

**Withdrawal.** A finding that turns out wrong is not deleted: its Status becomes
`withdrawn`, a line under the title says why and names what replaced it, and the index
lists it apart. A rule that cited it can then still be traced.
