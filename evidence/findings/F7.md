# F7 A count or list typed into prose goes stale in silence when what it describes changes, and stays true only when it is generated or checked

| Field | Value |
|---|---|
| Status | active |
| Topic | Context economy and agent prose |
| Grade | R4/S4 |
| Cases | roadkeep, polyweave, freewilly, winwright, Shio |
| Contrary | none |
| Harness facts | none |

## Claim

In every project a figure or an enumeration written into prose (a skill, a README, a
configuration comment, a contributing guide) was found wrong after the thing it described
changed, with nothing failing, and the remedies that held were to generate the number from
its source or to check the sentence against a measurement.

## Mechanism

A number typed into a sentence is true when it is written and has no link to what it
counts. The change that makes it false (a new page, a new block, a new workflow, a new key)
is made elsewhere, often by another session, and nothing reads the sentence at that moment.
An agent that later loads the prose trusts it, so a stale figure misleads the next session
rather than failing anything. A figure produced from the source, or a test that reads the
sentence against a measurement, has the link the typed one lacks.

## Independence

Five origins: each stale figure was written and went stale in its own project's files, so
each counts where it happened (grading rule 1). The remedies are also each project's own:
generation in freewilly (DD159) and Shio (the site's figures), and checks in Shio (SH974),
roadkeep (the figures sweep) and winwright (WW503). freewilly's typed-count rule and Shio's
site rule may both come from the shared user-level writing skill; that affects the count of
remedies, not of failures. Within freewilly the fault recurs after its remedy, since the
contributing guide was not covered by the generated counts.

## Counter-evidence

- winwright's case shows a check built from a typed list reproducing the fault it guards:
  the earlier gate held the example to nine typed names and missed the key for that reason.
  A check is a remedy only when it reads the source of the figure.
- Some typed figures are records of a moment rather than claims about the present, such as
  a ledger entry's count on the day it shipped; those do not go stale in this sense, and
  none of the observations above is of that kind.
- Shio's figures test is not recorded failing on a real sentence after it was written; the
  S4 grade rests on winwright's control.

## Grade

**R4**: a stale typed figure or enumeration is observed independently in all five
projects. **S4**: winwright's WW503 check encodes the claim (it fails when the prose no
longer matches what the build reads) and its commit records it failing on a control. The
counted observations elsewhere are S3: 25 against 28 in Shio, four against five and two
against four in freewilly, eight blocks against ten in polyweave, five places in roadkeep.
