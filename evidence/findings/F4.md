# F4 Served MCP tool schemas were measured as a fixed cost of every session and held by a failing budget, which forced trims or argued raises

| Field | Value |
|---|---|
| Status | active |
| Topic | Context economy and agent prose |
| Grade | R3/S4 |
| Cases | Shio, roadkeep |
| Contrary | none |
| Harness facts | H8, H9 |

## Claim

The two projects that serve MCP tools to their own agent measured the serialized tool
schemas as a cost paid at the start of every session, put a ceiling on it that fails the
build, and met every later addition by trimming a description or raising the ceiling with
a written reason; a third project chose a CLI over MCP on the strength of one of those
measurements.

## Mechanism

A tool's name, description and input schema are sent to the model so that it can call the
tool, whether or not the session ever does. A CLI verb reached through the shell costs
nothing until it is run. So each tool, and each paragraph added to a tool's description, is
a charge on sessions that never use it, and nothing surfaces the charge unless it is
measured. Whether all definitions are in fact sent up front depends on the harness (H9).

  A later tool raised it, "so the ceiling rose to 2500" [shio@821f18d74:docs/CHANGELOG.md#L369].
  One feature was built with no tool at all because "a tool schema is paid on every turn of every session (P3) and a coding agent has a shell" [shio@821f18d74:docs/CHANGELOG.md#L392].
- **roadkeep.** RK1059 recorded "the largest every-turn surface is measured and held by nothing" [roadkeep@91754240:docs/CHANGELOG.md#L645]

- **freewilly.** It serves no MCP tools. Its specification decides "CLI first; MCP only if a shell-less client ever matters" [freewilly@c1c2eaf:docs/specs/DD23-agent-first-freewilly.md#L120]

## Independence

Two origins. Shio invented the measured tool-list budget (SH132, 2026-07-26). roadkeep's
RK1059 came later from the same author, and describes itself as its own earlier argument
about the resident file "made about the schema" [roadkeep@91754240:roadkeep.toml#L77];
it counts as a second origin because roadkeep measured its own surface and changed the
remedy for a reason it states, a ceiling per tool rather than per list
[roadkeep@91754240:roadkeep.toml#L77-L79] (grading rule 2). freewilly's decision is a
copy of Shio's argument, as its own text says, and adds no origin. winwright is silent.

## Counter-evidence

- **The harness documentation disagrees with the mechanism as the corpus states it.** Shio
  and roadkeep both say the schemas are paid every session or every turn. The MCP page read
  on 2026-09-24 says that with tool search enabled, the default, Claude Code does not send
  all tool definitions to the model (H9). The measurements are of serialized size and are
  not in doubt; what each session actually pays under the current default is. A rule
  resting on this finding must name H9 and be re-checked against the harness version.
- The budget did not bound the surface in roadkeep: the session ceiling was raised twelve
  times in the comment's own record, from 63,700 to 69,665. What it did was make each raise
  a written decision.

## Grade

**R3**: two independent origins. **S4**: Shio's tool-list budget test encodes the claim,
and its ledger records it failing on a real change, three tokens over, answered by a trim.
The S4 concerns the size of the schema; the claim that the size is paid by every session is
contested by H9.
