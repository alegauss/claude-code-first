# Validation

The specification judged against the projects it came from, before it is offered to
others. Each audit has a report in the schema of [../spec/report.md](../spec/report.md)
(`<project>.json`), its rendering (`<project>.md`, generated by `scripts/report.py
render`), and notes on how it was run, the proposed classification of each failure, the
tasks offered to the project's owner, and what the audit cost (`<project>-notes.md`).

| Project | Report | Notes |
|---|---|---|
| roadkeep | [roadkeep.md](roadkeep.md) | [roadkeep-notes.md](roadkeep-notes.md) |

A report's verdicts are the audit's, not the owner's: a failure is classified and acted on
only when the owner decides. How far the audit itself can be trusted is measured
separately, against verdicts a person records independently.
